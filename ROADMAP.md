# Roadmap / Планы развития

Этот проект будет развиваться постепенно. Приоритеты могут меняться по результатам обратной связи.

This project will evolve over time. Priorities may change based on community feedback.

## Next / Далее

- удобная галерея готовых пресетов / a shareable preset gallery;
- расширенные настройки типографики текста песен / advanced lyric typography;
- улучшенная адаптация под маленькие и ультраширокие окна / better small and ultrawide layouts;
- автоматические проверки совместимости с новыми версиями Spotify / automated compatibility checks for new Spotify versions;
- упрощённая установка и обновление / simpler installation and updates.

## Ideas / Идеи

- анимированные фоновые эффекты с ограничением нагрузки;
- community themes and preset packs;
- дополнительные варианты режима погружения;
- accessibility profiles for contrast and reduced motion.

Предлагайте новые функции через GitHub Issues. Please suggest new features through GitHub Issues.
