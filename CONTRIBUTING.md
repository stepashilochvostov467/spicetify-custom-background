# Contributing / Участие в разработке

Спасибо за интерес к проекту. Thank you for your interest in the project.

## Сообщить об ошибке / Report a bug

Укажите версию Spotify и Spicetify, тему, страницу где возникла ошибка, шаги воспроизведения и скриншот. Please include your Spotify and Spicetify versions, active theme, affected page, reproduction steps, and a screenshot.

## Предложить функцию / Suggest a feature

Опишите задачу пользователя и желаемое поведение. Explain the user problem and the desired behavior.

## Pull requests

1. Создайте отдельную ветку / Create a focused branch.
2. Внесите минимальное связанное изменение / Keep the change focused.
3. Выполните `npm install`, `npm run build` и `npm test`.
4. Опишите результат и проверку в pull request / Describe the behavior and validation in the pull request.

Не добавляйте токены, личные данные, скачанные сборки Spotify или чужие изображения. Do not commit tokens, personal data, Spotify application files, or third-party artwork.
